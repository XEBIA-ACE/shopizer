### Admin-Configurable Currency Management

#### Summary
The aim is to allow an admin user to actively manage the currencies displayed on the storefront. This includes adding and removing currencies through a defined UI.

#### Features
- Admin users can add currencies to the storefront.
- Admin users can remove currencies instantly from the storefront.
- Currencies updated by the admin will reflect on the storefront in real-time.
- Users will be prompted to reselect a currency if it is removed during a session.
