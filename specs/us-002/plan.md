### Implementation Plan
1. **UI Integration**: Update the admin UI to enable adding/removing currencies.
   - Focus on responsive design to ensure a seamless integration.
2. **Backend Service**: Modify the currency management service to support real-time updates.
   - Emphasize transactionality and data integrity operations within the service.
3. **Middleware Layer**: Connect the UI changes to backend services to facilitate instant updates and correct handling of currency changes in user sessions.
4. **Testing**: Apply unit tests on frontend and integration tests on middleware layers to ensure functionality.
5. **Role Management**: Validate that unauthorized users cannot access currency management settings.
