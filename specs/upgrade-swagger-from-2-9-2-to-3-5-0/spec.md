## Upgrade Swagger from 2.9.2 to 3.5.0

### Business Need
Upgrade the Swagger API documentation tool from version 2.9.2 to 3.5.0 to ensure compatibility with modern development practices and tooling, leveraging new features and improvements in the newer Swagger specification.

### Requirements
- Ensure that all APIs are documented using the Swagger 3.5.0 specification.
- Retain any custom modifications made in the earlier documentation.
- Verify that all annotations and configuration files align with the new Swagger version.

### Constraints
- The upgrade should not introduce breaking changes to existing API consumers.
- Maintain existing CI/CD pipelines without disruption.

### Target Application
- **Name:** Shopizer-3.2.5
